# Sidebar plan usage meter

USG-B builds on USG-A PR #285, original head `53748de5fdd8e8d03019e0d77eaf99a4e63c4286`, rebased onto main `949624b`. Both PRs remain unmerged.

The desktop sidebar and phone drawer show the summary API's plan name, cent-accurate amount, capped display percent, account-calendar reset date and conditional own-key label. At 80% the meter says Near limit; at 100% it says Limit reached. API plans without a dollar allowance show No limit without a progress element. Unknown CLI quota says Quota unavailable, never No limit.

The same rendering is used by Models & access and the dashboard meter. Dashboard spending and daily cost use the shared plan accounting. Sidebar reads refresh on usage SSE, run idle, reconnect, connection changes, focus and a visible-page interval. Slow reads retain the previous values and geometry; failures identify that an update is unavailable. The shared reader discards data and pending results when accounts change.

Expanded button names come from the visible content, preserving FIX-A11Y #283's naming approach. The collapsed control retains a 40px visible size, a 44px pointer target and an explicit name containing the amount and quota state. Short viewports only omit the reset line.
