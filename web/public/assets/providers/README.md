# Provider marks

These local SVGs use the brands' recognizable monochrome marks: Claude's starburst (not the Claude Code pixel mascot), OpenAI's knot, OpenRouter's branching arrow, xAI, Gemini, Meta, Mistral, DeepSeek, Qwen, Moonshot and Cohere.

Source: the corresponding SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/05260484d9f4de68f90cc87a634ae68fa4043efd/packages/static-svg/icons), revision `05260484d9f4de68f90cc87a634ae68fa4043efd` (MIT). Each path is unchanged. The outer sizing and title were replaced by a reusable `mark` group. Brand trademarks remain the property of their respective owners. Brand references include https://claude.com, https://openai.com/brand, https://openrouter.ai and https://x.ai.

ProviderMark uses a 16px square and currentColor for the monochrome on-light/on-dark treatment. Adjacent text supplies the accessible name; icon-only uses must pass a label. All supported catalog author marks are bundled to avoid a network icon lookup or a monogram replacing a known brand. The legacy claude-code.svg is not used for plan or model labels.
